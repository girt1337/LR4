# План оптимизации проекта «Северный маршрут» (LR4)

## 1. Текущее состояние

- Один файл [`index.html`](../index.html:1) — HTML, CSS (`<style>`) и JS (`<script>`) в одном месте.
- Лендинг: шапка с навигацией, hero-блок, статистика, «О клубе», маршруты, преимущества, отзывы, контактная форма, футер.
- 6 внешних изображений с Unsplash, системный шрифт (без webfonts), 1 скрипт (~15 строк), 3 медиа-запроса.
- Семантика в целом корректная: один `<h1>`, `<main>`, `<section>`, `<article>`, `<blockquote>`, `<label for>`, `aria-expanded` на бургере.

## 2. Перечень технических проблем

### 2.1 Производительность и загрузка
| # | Проблема | Где | Влияние |
|---|----------|-----|---------|
| P1 | Нет `loading="lazy"` и `decoding="async"` у изображений ниже первого экрана | строки 22–26 | Лишний трафик, медленный старт |
| P2 | Нет `srcset`/`sizes` — на мобильных скачивается полноразмерное изображение | строки 20–26 | До 2–3× лишнего трафика |
| P3 | Нет `width`/`height` у `<img>` | строки 20–26 | CLS (сдвиг макета) при загрузке |
| P4 | Нет `preconnect`/`dns-prefetch` к `images.unsplash.com` | `<head>` | Задержка первого изображения |
| P5 | `backdrop-filter` без `-webkit-` префикса | строка 7 | Не работает в Safari, нет фолбэка |
| P6 | Нет `fetchpriority="high"` для hero-изображения | строка 20 | Медленный LCP |

## 3. Целевая архитектура

### 3.1 Структура файлов (без сборщика — учебный проект)

```
LR4/
├── index.html
├── css/
│   ├── tokens.css        # :root переменные, шрифты
│   ├── base.css          # reset, типографика, утилиты
│   ├── layout.css        # header, hero, section, footer, grid
│   ├── components.css    # кнопки, карточки, форма, навигация
│   └── responsive.css    # все медиа-запросы
├── js/
│   └── main.js           # модуль: меню, форма, reveal, data-trip
└── assets/
    └── img/              # локальные оптимизированные изображения
```

### 3.2 CSS-архитектура
- **Design tokens** в [`css/tokens.css`](css/tokens.css): цвета, радиусы, тени, отступы, брейкпоинты — единый источник правды.
- **BEM-подобная нотация** для компонентов (`.trip-card`, `.trip-card__image`).
- **CSS-слои** `@layer` (tokens → base → layout → components → utilities) — предсказуемый каскад.
- Переменные для «магических чисел»: `--header-height`, `--scroll-offset`.

### 3.3 JS-архитектура
- Один модуль [`js/main.js`](js/main.js) с функциями: `initMobileMenu()`, `initReveal()`, `initLeadForm()`, `initTripSelect()`.
- Защита от отсутствия элементов (`if (!el) return`).
- Reveal-анимация: фолбэк через `@media (scripting: none)` + класс `no-js` на `<html>` — контент виден без JS.

### 3.4 Изображения
- Локализация: скачать 6 изображений в `assets/img/`, сжать (WebP/AVIF + fallback).
- `srcset`/`sizes` для адаптивной отдачи, `width`/`height` для устранения CLS.
- `loading="lazy"` + `decoding="async"` для ниже-фолдных, `fetchpriority="high"` для hero.
- `preconnect` к CDN, если остаёмся на Unsplash.

### 3.5 Доступность и SEO
- Skip-link, `:focus-visible`, Escape для меню, `aria-current`.
- OG/Twitter-метатеги, JSON-LD (Organization + FAQ), canonical, favicon, theme-color.
- Проверка контраста, увеличение `--muted` до AA.

## 4. Поэтапный план

### Этап 1 — Рефакторинг структуры (без изменения поведения)
1. Разбить CSS на 5 файлов по слоям, подключить через `<link>`.
2. Вынести JS в [`js/main.js`](js/main.js) с `defer`.
3. Ввести design tokens и заменить магические числа.

### Этап 2 — Производительность
4. Локализовать и оптимизировать изображения (WebP, размеры под брейкпоинты).
5. Добавить `srcset`/`sizes`, `width`/`height`, `loading="lazy"`, `fetchpriority`.
6. Добавить `preconnect`/`dns-prefetch`.

### Этап 3 — Доступность и надёжность
7. Фолбэк для `.reveal` без JS (`no-js` класс + `@media (scripting: none)`).
8. Skip-link, `:focus-visible`, Escape-закрытие меню, `aria-current`.
9. Исправить контраст, добавить `-webkit-backdrop-filter`.

### Этап 4 — SEO и метаданные
10. OG/Twitter-метатеги, JSON-LD, canonical, favicon, theme-color.

### Этап 5 — Верификация
11. Проверка Lighthouse (Performance, A11y, SEO, Best Practices).
12. Проверка без JS и на мобильном вьюпорте (Puppeteer).

## 5. Критерии готовности
- Lighthouse Performance ≥ 90, A11y = 100, SEO ≥ 95.
- CLS = 0, LCP < 2.5s (на throttled-сети).
- Страница полностью читаема при отключённом JS.
- Каждый CSS-файл < 400 строк, читаем без горизонтального скролла.
